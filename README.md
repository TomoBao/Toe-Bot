# 🦶 Toe Bot

Official website and policies for a simple Discord command bot.

## GitHub Pages
Upload all five files to the repository root. In Settings → Pages, choose Deploy from a branch, main, / (root), and Save.

- Homepage: https://tomobao.github.io/Toe-Bot/
- Terms: https://tomobao.github.io/Toe-Bot/terms.html
- Privacy: https://tomobao.github.io/Toe-Bot/privacy.html

Before publishing, verify that the privacy policy matches actual bot behavior, including hosting logs, libraries, data retention and sharing. Update the contact method if needed. Never commit bot tokens or credentials.
